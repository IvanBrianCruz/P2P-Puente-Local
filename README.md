# P2P Local Bridge - Manual de Uso

## 🚀 Cómo funciona ahora (Experiencia 100% Web):
1. **Doble clic a `P2P-Local-Bridge.exe`**:
   - Ya **no requiere interactuar con la terminal**.
   - Abre de forma instantánea tu navegador en la pantalla de bienvenida y configuración (`http://localhost:4000/__bridge/admin`).
2. **Ingreso de datos en la Web**:
   - Escribes el puerto de tu proyecto (ej. `3000`, `5173`, `8080`) directamente en el formulario visual.
   - Opcionalmente puedes definir o editar los datos de tu Wi-Fi.
   - Haces clic en **"✨ Desplegar Puente Local"**.
3. **Panel de Control y Códigos QR**:
   - Se activará el puente y verás el enlace a tu web en la intranet.
   - **Visualización ampliada de QRs**: Haz clic sobre cualquier código QR (el del proyecto o el del Wi-Fi) para abrir una **ventana emergente grande** con el código en alta definición, ideal para proyectar en pantallas o que escaneen desde lejos.
   - Puedes cambiar el puerto en cualquier momento con el botón **"⚙️ Cambiar Puerto"**.
